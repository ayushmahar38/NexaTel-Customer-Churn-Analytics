# NexaTel Customer Churn Analytics 📊

An end-to-end data analytics workflow designed to identify key churn indicators, analyze customer demographics, and surface actionable insights for telecom customer retention.

---

## 🛠️ Tech Stack & Tools
* **Data Processing & SQL:** Jupyter Notebook, Python, SQL
* **Data Visualization:** Tableau Public (Interactive Executive Dashboard)
* **Environment:** macOS

---

## 📈 Key Findings & Metrics
* **Overall Churn Rate:** 18.43%
* **High-Risk Segments:** Identified specific high-risk cohorts (including a 27.53% churn risk segment and 23.31% contract churn) requiring targeted intervention.
* **Revenue Exposure:** Analyzed monthly revenue exposure to prioritize retention campaigns effectively.

---

## 🚀 Project Workflow
1. **Data Cleaning & Preprocessing:** Cleaned raw telecom datasets (customer profiles, billing, subscriptions, support tickets) using Python and SQL within Jupyter Notebooks.
2. **Exploratory Data Analysis (EDA):** Queried databases to uncover customer segmentation patterns, contract types, and service usage correlations with churn.
3. **Dashboarding & Visualization:** Built and published an interactive executive dashboard on Tableau Public.
